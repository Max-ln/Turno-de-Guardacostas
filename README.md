# Turno de Guardacostas

Videojuego 2D de concientización sobre la contaminación marina (ODS 14, 12 y 6), hecho con Python y pygame-ce.

## Descripción

El jugador es el equipo de guardacostas de una bahía. Los barcos sueltan plásticos y manchas de hidrocarburo, y debe limpiarlos con la herramienta correcta (red, barrera de contención o material absorbente) antes de que la salud del mar llegue a cero. Al terminar cada turno (nivel) aparece una ficha con un dato real sobre contaminación marina y su fuente.

Este repositorio contiene las primeras fases del ciclo de vida del proyecto.
